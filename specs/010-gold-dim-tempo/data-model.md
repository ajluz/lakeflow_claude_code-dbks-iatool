pipeline dataset. Grain: one day. SCD type 1 (attributes never change). `TBLPROPERTIES

## Rules (verified by query, not by expectation)

- `sk_tempo` unique and not null; `data` unique among days.
- Only the members have `data IS NULL` and negative keys.
- 120 days have `fl_ultimo_dia_mes` = true (one per month, January 2021 – December 2030).
- `fl_dia_semana` = false exactly when `dia_semana_int` is 1 or 7.

## Lifecycle

| Event | Effect |
|---|---|
| First run (table absent) | Table created; 2 members and 3,652 days inserted |
| Run again, same period | Nothing inserted or changed |
| Run again, end date moved forward | Only the new days inserted; existing rows unchanged |
| Run on a table with repeated days | Script stops with an error before inserting; the owner decides on a drop |

## Relationships

None outgoing (Principle VII: a dimension references no dimension). Future facts
(`fato_venda`, `obt_acesso`) will resolve `sk_tempo` by joining their event date on
`data`, falling back to `-1`.
